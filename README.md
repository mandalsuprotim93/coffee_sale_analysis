# Coffee Shop Analysis

## 📌 Project Overview
This project analyzes coffee shop performance using sales, customer behavior, and operational data. The goal is to identify trends, optimize revenue, and improve customer satisfaction.

## 📂 Dataset
- Source: `coffee_shop_analysis.xlsx`
- Contains information on:
  - Daily/Monthly sales
  - Product categories (e.g., espresso, latte, pastries)
  - Customer demographics
  - Order cancellations and reviews
  - Revenue breakdown by location or type

## 🔍 Analysis Performed
- Data cleaning and preprocessing
- Pivot tables for revenue, cancellations, and product performance
- Visualizations (bar charts, line graphs, pie charts)
- Summary of key findings

## 📊 Key Insights
- Best-selling product categories
- Peak sales hours/days
- Cancellation trends and possible causes
- Customer review sentiment
- Overall revenue growth patterns

## 🚀 How to Use
1. Open the Excel file `coffee_shop_analysis.xlsx`.
2. Navigate through the pivot tables and charts.
3. Review the summary sheet for consolidated insights.

## 🛠 Tools Used
- Microsoft Excel (Pivot Tables, Charts)
